# 📊 Student Attendance Tracker

A clean and responsive **Student Attendance Tracker** built using **Vite + React** with **Tailwind CSS**.
It uses API-based student data and includes charts for better attendance visualization.

🔗 Live Demo: https://student-attendance-tracker-sp.netlify.app/

---

## 🚀 Features

* Add and manage students
* Mark attendance (Present/Absent)
* Fetch student data from API
* Visualize attendance using charts
* Responsive and clean UI

---

## 🛠️ Tech Stack

* React (Vite)
* Tailwind CSS
* JavaScript
* API Integration
* Chart Library

---

## ⚙️ Setup

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd student-attendance-tracker
npm install
npm run dev
```
